# ccgt-demo

Klikalne demo workflow harmonogramu CCGT. Specyfikacja: [SPEC.md](SPEC.md) (obowiązująca).

**Demo na danych syntetycznych — brak związku z rzeczywistym projektem.** W repo wolno trzymać wyłącznie pliki `PL5001_SYNTH_*` (guard: `npm run guard`).

## Uruchomienie
```bash
npm install && npm run dev
npm test && npm run build
```

## Założenia (niejasności w specyfikacji)
- Wersja `React 18`, `Tailwind 3`, `Vite 6`.
